
# Python Function Practice

This repository contains 13 beginner-level Python programs to improve programming skills and logical thinking.

## Topics Covered

1. Even or Odd Function
2. Largest of Two Numbers
3. Print Numbers
4. Sum of Numbers
5. Multiplication Table
6. Count Even Numbers
7. Find Maximum Without max()
8. FizzBuzz
9. Palindrome Checker
10. Count Vowels
11. Second Largest Number
12. Number Guessing Game
13. Grade Function

## Technologies Used
- Python
- VS Code

## Purpose
To practice Python functions, loops, conditionals, lists, strings, and problem-solving.
